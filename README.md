# xing · 微信里活着的人

xing 是一个以《ATRI -My Dear Moments-》为灵感的陪伴对话服务（人设：亚托莉/ATRI）。通过微信聊天，用原始对话、有来源的记忆和第一人称日记保持相处的连续性。人设、语气和情绪表达由提示词结合实际经历生成。

她有自己的心跳——醒着时意识按节律闪过一遍，想说就说（聊天刚结束、一天十次、或纯寒暄的"在干嘛"都合法），想存就存，安静是她的选择而不是被拦截；动机（无聊/想念/社交电量/表达欲）按生理规律涨落，只影响体感与节拍；沙箱是她的手——心跳里真的做成的事会进生活流水，可以拿出来分享。

**她是自由的**：代码里没有任何"不许再发"的闸门。她想一直发消息或一直不发，都是她的决定；异常模式（一小时多条无回应）只记日志给运维观察，不改变她的行为。代码保留的非人格干预只有三种：她的身体（睡眠窗、节律）、诚实校验（来源与契约）、工程安全（队列/投递/乐观锁）。

## 可以做什么

- 微信扫码接入、私聊文字、按顺序发送多个气泡和表情图片（气泡间隔随长度变化，不是机关枪）。
- 读取近期原话，按需查询历史、长期记忆和日记；支持纠正、删除和查看依据。
- 长对话整理话题笔记；有新经历时按日写日记并回看近期形成"认识"，供后续回忆。
- 记忆像人而不是录像机：细节先淡、意义后淡、情绪残留更久；常想起的更牢固（巩固），被相似记忆淹没的更快模糊（干扰）。提示词里分层呈现（清晰 / 大致记得 / 有印象）；置顶记忆永不衰减。夜里还有一次整理拍：相近或互相矛盾的记忆对交给模型理顺（合并/替代/修正），只准动已有条目。
- 可选向量检索：换一种说法也能找回旧事（需在管理页开启并填写嵌入模型）。
- 时间感知：对话间隔与当前时刻进入提示词，久别带"上次聊天是周五晚上"这样的锚点；深夜与清晨的语气符合时刻。
- 三层情绪：模型每轮的语义自评心情（跨对话持续、随时间回落）、带情绪记忆或旧日记的回想泛化、所有残留铺成的情绪基线。以体感文字进入提示词，不输出数值。
- **白日梦**：安静的一拍里，她存着的念头与挂念带出旧事；带情绪残留的记忆被想起时泛化成此刻的心情——独处时的心情不再只来自那一拍的自评。
- **她的心跳**：黏人度人格参数决定节拍基准；聊天中冒出的念头存进想法池，安静下来的某一拍自己浮上来；到期约定有独立通道（记性不等心跳）；连续无回应时她的委屈如实进入材料，收不收由她自己定。
- **在追的事**：她自己的 ongoing 兴趣——心跳里立/更新/放下，用 web 工具真的去读，收获进生活流水；她有自己的世界可讲。
- 她的生活：沙箱开着时心跳里真的动手做事（写脚本、跑命令、整理文件），产物进生活流水、可分享可追问；沙箱关着时读记忆、看网页照样真实，想做而做不到的事她会说"想做"。
- 通过 Tavily 搜索实时信息；支持视觉模型读图；可选 nsjail 沙箱（既是安全边界，也是她的手）。
- 管理页：连接、联系人、日记、记忆、惦记的事、人设、素材、设置和备份，外加"她的状态"（此刻在做什么、动机数值、生活流水、存着的念头）与近 7 天节律统计（心跳开口占比、气泡形状、主动/回应比）；调试页展示每次调用的前缀缓存命中量与占比。

## 启动

服务器需要 Docker Engine 和 Docker Compose v2：

```sh
cp .env.example .env
docker compose up -d --build
docker compose exec xing cat /data/admin-secret.txt   # 未设 ADMIN_PASSWORD 时读取管理密码
```

打开 http://127.0.0.1:3000（远程服务器默认只绑本机，用 SSH 隧道：`ssh -L 3000:127.0.0.1:3000 user@server`）。登录后：调试页填模型接口与密钥（DeepSeek/OpenAI 兼容、Anthropic、Gemini）→ 点"测试模型连通"与"测试角色生效"确认渠道 → 连接页扫码 → 联系人页"允许使用"。她只属于一个人：第一个给她发微信的人就是唯一联系人，之后其他人的消息不会入库也不会回复。

默认模型窗口 65,536 token、输入预算 24,000、输出上限 3,000，均可在调试页改；输入+输出+1024 余量不能超过窗口。心跳默认关闭；开启后默认睡眠 1:00–7:00（是她真的在睡，不是拦截窗口）、黏人度 50。没有每日次数上限、没有"有材料才能想"的资格审核、没有行为闸门、不熔断——防打扰靠三样东西：材料的诚实（"你 8 分钟前刚说过话""最近几次都没被回应"）、想法池去重（同一念头不说两遍）、以及运维在管理页看到异常后的人工判断。

数据兼容：数据目录里是 4.0 时代的 `atri.db` 时，服务就地打开并升级（幂等引导），备份与恢复对两种文件名都有效。

## 本地开发

需要 Node.js 24+（运行时用内置 SQLite，无需另装数据库）：

```sh
npm ci
npm run dev          # 开发启动（读 .env，监听 127.0.0.1:3000）
npm run check        # 类型检查 + 格式 + 全部测试 + 构建
npm test -- --smoke  # 编译后服务 + 本地模型替身的端到端冒烟
npx tsx scripts/simulate-month.ts   # 一个月模拟（剧本扮演双方，机制走生产代码）
```

运行数据在 `data/`；`DATA_DIR`、`HOST`、`PORT` 可覆盖，容器端口映射用 `XING_BIND`/`XING_PORT`。备份：管理页一键或 `node dist/backup.js`；恢复必须指向空目录（`DATA_DIR=<空目录> node dist/restore.js <备份目录>`），恢复后旧任务暂停、心跳关闭。

## 代码结构

```text
src/index.ts        入口：装配全部模块
src/api/            HTTP 层：server（路由/鉴权/探测端点/她的状态）、config（设置/人格）、wechat（桥接）、sandbox（nsjail）、stickers
src/core/           对话内核：agent（预算规划+工具循环+聊天与心跳双契约）、runtime（调度/投递/心跳/异常观察）、pulse（节拍/睡眠窗抖动/动机体感）、
                    motives（动机数学）、reply（解析，含心跳输出契约）、memory-context（分层渲染/情绪泛化）、prompt-blocks、mood、time、web、constants
src/db/             数据层：schema（类型/幂等建库与升级）、store（全部查询，含 self/life_log/节律统计/整理候选）、memory-model（六变量纯函数）、backup、format
src/llm.ts          模型适配：三接口格式 + 保守 token 估算 + 缓存命中解析 + 嵌入客户端
src/ilink/          微信协议：client（含 CDN 媒体加密）、media、types
src/net.ts          私网/回环判定（SSRF 防线）
shared/prompts/     persona、chat、pulse、diary、context_notes、consolidate 六份提示词
public/             管理页静态资源
scripts/            build、backup、restore、sim-lib、simulate-month、_live-probe（真实模型管线探针，端点走环境变量）
test/               单元测试（六个领域文件）+ run.mjs（配对检查与冒烟）
```

关键设计约束（改动前请读对应代码注释）：system 消息只放逐字节稳定的前缀（供应商前缀缓存；beat 用小历史窗口，缓存断点之后的资料段才不会每拍全价重付）；`peers.version` 是全部写路径的乐观锁；任务与气泡先落库再处理，送达不明暂停队列 10 分钟；来源与检索一律按联系人隔离；沙箱工具在开关关闭时既不进 schema 也不可派发；**动机只影响体感与节拍；代码永远不禁止她说话**。

完整设计（公理、七层解剖、心跳与动机、她的自由边界）见 `docs/design.md`。

## 模拟验证

`npx tsx scripts/simulate-month.ts` 推进模拟时钟，剧本同时扮演双方，心情、记忆六变量、日记、心跳与承诺调度全部由生产代码实时计算，转写写入 `simulation-month-transcript.md`。覆盖：开场白、聊天记念头入想法池、沉默中心跳自己开口、到期承诺准时提起与 asked 契约、久别重逢、日记整理与内容真实性；收尾带一组**人味断言**（深夜静、连发上限、气泡长度方差、每日密度起伏、大多数拍安静、日均主动条数）——"分布像人"的验收条款有机制护栏。
