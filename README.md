# xing — 微信里活着的一个人

她不是聊天机器人。她是一个只属于一个人的、活在微信里的虚拟人：有自己的身体节律、情绪、记忆、
念头、手（沙箱）与眼（联网），说话是她自己的决定——代码从不替她决定说不说。

灵感人设来自《ATRI -My Dear Moments-》的亚托莉；微信协议来自 WeChat-AI 项目（见 `licenses/`），
其余代码以 PolyForm Noncommercial 许可发布（见 `LICENSE`）。**仅供个人学习与陪伴使用，非商业。**

## 她由什么构成

| 层   | 是什么                                                                                             | 在哪里                                            |
| ---- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 意识 | 心跳节拍（黏人度→18–90 分钟/拍，动机伸缩，±25% 走神）、睡眠窗（按日抖动 ±45 分钟）                 | `src/domain/state.ts` `src/domain/rhythm.ts`      |
| 身体 | 沙箱是她的手（nsjail 命名空间隔离），联网是她的眼（Tavily+公开网页，私网拦截）                     | `src/sandbox.ts` `src/web.ts`                     |
| 情绪 | 三轴心情脉冲（愉悦/精力/耐心，小时级衰减）+ 记忆情绪残留的底色；心情只影响语气，从不拦截行为       | `src/domain/mood.ts` `src/domain/state.ts`        |
| 记忆 | 六变量数学（细节衰减 λ=λ₀(1−0.55                                                                   | E                                                 | )(1−0.65C)(1+0.9I)、意义、情绪残留、巩固、干扰）；模糊的记忆只给要旨，精确原文要显式查历史 | `src/domain/state.ts` `src/domain/memory.ts` |
| 关系 | 有来源的约定（到期唤醒，记性不等心跳）、挂念、念头（送达才退场，新证据才重立）                     | `src/domain/commitment.ts` `src/domain/memory.ts` |
| 经历 | 单一事件流：收到/说出/做成/没做成/日记。**“说过”只在确认送达后记账**，“做过”只有成功工具回执能支持 | `src/storage/journal.ts`                          |
| 表达 | 聊天与心跳共用一个思考循环、一份稳定前缀（人格+规则+协议）；气泡节奏按长度即打字时间               | `src/domain/mind.ts` `src/domain/material.ts`     |
| 自由 | 代码里没有任何“不许她说话”的分支——安静是她的选择，连发是她的选择；睡眠窗是身体，不是闸门           | 公理，测试钉住                                    |

## 快速开始

```sh
cp .env.example .env      # 填 ADMIN_PASSWORD 与 LLM_* 密钥
npm install
npm run check             # typecheck + 格式 + 全部测试 + 构建
npm run dev               # 本地开发（管理页 http://127.0.0.1:3000）
docker compose up -d --build   # 生产部署（nsjail 源码编译，首次构建较慢）
```

部署后：管理页 → 调试页填模型 → 连接页扫码 → 联系人页“允许使用”→ 人设页开启心跳。
管理密码未设置时写在数据目录 `admin-secret.txt`。

## 从旧版（v5.x）迁移

```sh
node dist/migrate.js <旧 atri.db> <新内核.db>
```

消息、记忆（六变量投影）、约定、念头、心情、日记、微信会话凭据、旧向量全部原样迁移；
老库文件不动，验收后再切换。备份与恢复：`npm run backup` / `npm run restore`。

## 设计公理

1. **生理归代码，决策归模型**：代码只算确定性、可测试的量（衰减、节拍、动机积分）；想不想说、
   说什么，永远是模型在真实材料上的决定。
2. **诚实材料代替一切闸门**：没有配额、没有冷却硬闸、没有资格审核。防打扰靠三样：材料的诚实
   （“你 8 分钟前刚说过话”）、念头去重（送达退场、新证据重立）、送达与行动分开记账。
3. **诚实红线**：没做过的不说做过；工具回执是行动的唯一凭证；模糊记忆不许补细节；做不到就说想做。
4. **她只属于一个人**：全局一份自我、一份情绪、一份生活；这是产品本身的排他，也是架构的承重墙。
