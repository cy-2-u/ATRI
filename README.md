# ATRI — QQ 里活着的一个人

她不是聊天机器人。她是一个活在 QQ 官方机器人里的虚拟人：有自己的心跳节拍、情绪、记忆、
念头、手（沙箱）与眼（联网）。说话是她自己的决定——代码从不替她决定说不说。

本版融合三个历史版本：以 QQ 官方 API 版的工程底盘（事件账本 / 投递完整性 / 工具回执幂等 /
网关断线恢复）为骨架，移植初版的"活人器官"与管理界面视觉，数据层按 QQ 底盘契约重接。

## 她由什么构成

| 层 | 是什么 | 在哪里 |
| --- | --- | --- |
| 意识 | 心跳节拍（黏人度→约 18–90 分钟/拍，动机伸缩，防骚扰收敛），夜间整理拍 | `src/state.ts` `src/runtime.ts` |
| 身体 | 睡眠窗按日抖动 ±45 分钟，熬夜（18 点后热闹）推迟入睡 ≤60 分钟；睡着的拍推到醒来 | `src/state.ts` `src/runtime.ts` |
| 情绪 | 三轴脉冲（愉悦/唤醒/耐心）+ 记忆情绪残留的底色 + 心情轨迹原文浮回；只影响语气，从不拦截行为 | `src/state.ts` `src/context.ts` |
| 记忆 | 六变量衰减（细节/意义/情绪/巩固/干扰），模糊记忆只给要旨；identity 需要 2 处真实经历 | `src/store.ts` `src/memory.ts` |
| 关系 | 黏人度由相处每天演化（密度、回应、落空），配置只是种子；她对你的印象由夜间整理修订 | `src/state.ts` `src/context.ts` |
| 经历 | 单一事件流 + 念头（期待）+ 版本化约定（承诺绑定气泡，平台接收后才立约）+ 夜间日记 | `src/store.ts` |
| 表达 | 聊天/心跳/夜间共用一个思考循环、一份稳定前缀；气泡按长度停顿，像在打字 | `src/mind.ts` `src/context.ts` |

## 省 token 的硬设计

1. 心跳拍不带全量历史（只有聊天轮带）；2. 图片历史只注入最近 2 张；
3. 情绪/动机渲染成中文短句而非 JSON 数值；4. 夜间一拍三用（日记+记忆归拢+印象修订）；
5. 稳定前缀缓存 + 旧段冻结分层摘要；6. 词面召回（FTS5）免费优先，语义向量只在词面薄时调用。

## 快速开始

```sh
npm install
npm run check        # typecheck + 全部测试 + 构建
npm run dev          # 管理界面 http://127.0.0.1:3010（自带表情库在首次启动时自动灌入）
npm run restore -- <备份.atri> <目标新目录>   # 从加密备份恢复（只写新目录）
```

配置：管理界面 → 系统页填模型渠道 → QQ 连接抽屉填 AppID/Secret 并启用。收到第一条私聊她就是活的：
默认处理消息+自主心智，开关降级为「想关时才碰」，不需要手动点燃仪式。
管理密码未设置时写在数据目录 `admin-secret.txt`。

服务器部署：`mkdir -p /srv/atri/data && chown -R 1000:1000 /srv/atri/data`，然后
`docker compose up -d --build`；密码在 /srv/atri/data/admin-secret.txt。
沙箱是常驻容器 `atri-sandbox`——她的窝：可写环境跨轮保留、崩溃自动拉起，作品文件始终在
/srv/atri/data/works；重置她的窝 `docker rm -f atri-sandbox`，文件不受影响。需要 Docker 才有沙箱执行（`execute` 工具）；其余功能（读/写/搜索/画图/表情）无需 Docker。

## 设计公理

1. **生理归代码，决策归模型**：衰减、节拍、黏人度是确定性数学；想不想说、说什么永远是模型的决定。
2. **诚实材料代替一切闸门**：没有配额、没有冷却硬闸。防打扰靠材料的诚实与节拍收敛。
3. **诚实红线**：没做过的不说做过；工具回执是行动的唯一凭证；模糊记忆不补细节；未知不冒充成功。
4. **接收 ≠ 已读**：平台回执、用户已读、履约证据分开记账。
