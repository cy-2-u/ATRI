# ATRI 主动框架 v3：活着的人（Living Self）

状态：已实施（本仓库 v4.0.0 即本设计的落地）。设计历经三轮推翻：v2 的"事件驱动审批"把念头当申请、代码当审批官；讨论中先改成"有材料才想"，再改成"意识流常开"，最终确定为本文的形态。旧的 v2 设计文档与行号快照已随重写移除，git 历史可考。

## 设计公理（来自调研）

1. 可信的活人 = 记忆流 + 检索 + 反思 + 计划（Stanford Generative Agents）。记忆流本仓库已有（六变量），反思并入日记，计划由心跳的晨拍承担。
2. 自主行为由会衰减、会被满足的动机驱动（The Sims 的 needs-based AI）。动机是生理，决策是人格。
3. 大多数日常消息是连接性的（phatic communion），不是信息性的："在干嘛""在想我吗"没有信息量，功能是维持连接本身。
4. 频率是人格的表达（依恋风格），不是规则的结果；时机与相关性决定同一条消息是温暖还是打扰。
5. 她的睡眠 = sleep-time compute：日记、巩固、向量回填本来就是凌晨在跑的离线整理。

## 七层解剖

```
L6 表达    消息/表情/beat/真实产物分享
L5 关系    想法池/承诺(开环)/挂念/作息数据(24桶)/纪念日
L4 记忆    六变量记忆流 + FTS + 向量
L3 心理    情绪(三轴)/委屈感(读空气内化)/想法池
L2 意识    心跳：想 → 做 → 说/存/过（一次调用）
L1 内稳态  无聊/想念/社交电量/表达欲（衰减-满足）
L0 身体    沙箱=手 / 网络=眼 / 时钟 / 睡眠
```

## 心跳（src/core/pulse.ts + runtime.schedule）

- 全局单一意识（不是每联系人一份）；醒着常开，睡着（sleepStart–sleepEnd）无心跳——是生理不是拦截。
- 节拍间隔 `nextBeatDelayMs`：基准由黏人度 0–100 决定（90→18 分钟），聊天余韵加密到 5 分钟内，想念/无聊饥饿 ×0.55，社交见底 ×1.6，±25% 走神抖动，钳制 3 分钟–4 小时。
- 一拍 = 一次模型调用（与聊天同一个 API，无模型分层），材料全部真实：时间、能力边界（手可用/只有眼/只能想）、`self` 状态、生活流水、动机体感、对话线程（真实间隔 `renderTimeGap`、作息桶、无回应次数）、想法池、到期承诺。
- 输出契约 `parsePulseOutput`：`speak`（messages 与聊天同格式，寒暄类消息合法且重要）/ `muse`（念头存入想法池，topicKey 为内容哈希）/ `nothing`；任意一拍可携带 `activity`（这拍真实做成的事，走工具轮，产物进生活流水）与 `selfActivity`。
- 发送决定权完全在模型。代码只保留两个非性格干预：睡眠（生理）与故障保险丝（一小时 ≥2 条无回应心跳 → 熔断并告警，一小时后自动恢复）。

## 动机（src/core/motives.ts）

| 动机     | 机制                                               | 代码职责       |
| -------- | -------------------------------------------------- | -------------- |
| 无聊     | 单调时间的确定函数（4 小时拉满），做事/聊天归零    | 导出量，不入库 |
| 想念     | 距上次开口的时间（20 小时拉满），对方活跃时段 ×1.4 | 按联系人导出   |
| 社交电量 | 聊天每条 -0.05，独处 6 小时回满                    | 积分，入库     |
| 表达欲   | 心情事件与成就抬升，2 小时半衰                     | 积分，入库     |

动机只改变材料的措辞与节拍密度，永远不禁止行为。

## 她的生活（真实性的边界）

- 沙箱开着 = 她的手：心跳里真的写脚本、跑命令、整理目录，产物进生活流水（`life_log` 环形 200 条），分享可附真实文件。
- 沙箱关着 = 纯精神生活：检索记忆、回看日记、读网页（web 工具不依赖沙箱）全部真实。
- 诚实红线：能验证的必须真做过；不伪造物理证据；想做而做不到的事说"想做"。心跳材料明确标注她此刻的能力边界。

## 保留与删除

保留：到期承诺独立通道（记性不等心跳）、想法池 topicKey 去重、outbox/乐观锁/beat/崩溃安全、六变量记忆、心情三轴。删除：seedIdleMuse、36 小时冷却、proactiveAllowed 时段/冷却硬闸、evaluateInitiatives/considerInitiatives、proactiveAfterHours、一切每日配额。

## 验收

- 可归因：任何一条主动消息都能在 `/api/self` 与生活流水里查到由头（念头/流水/动机/承诺）。
- 分布像人：早晚密、深夜静、有日子十条有日子零条，寒暄占比合理。
- 单元测试 40 个覆盖动机数学、节拍边界、心跳契约、保险丝、乐观锁与 EACCES 回归；`scripts/simulate-month.ts` 以模拟时钟跑通"开场白→聊天记念头→沉默中心跳开口→承诺准时提醒→日记整理"全链。
