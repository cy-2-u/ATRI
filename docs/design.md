# xing 设计：活着的人

本文是 xing 的完整设计记录：公理、分层、心跳与动机的机制，以及"她的自由"的精确边界。实现在 `src/`，行为验证在 `test/` 与 `scripts/simulate-month.ts`。

## 设计公理

1. **可信的活人 = 记忆流 + 检索 + 反思 + 计划**（Stanford Generative Agents）。记忆流是六变量模型，反思并入日记与夜间整理，计划由心跳承担。
2. **自主行为由会衰减、会被满足的动机驱动**（The Sims 的 needs-based AI）。动机是生理，决策是人格。
3. **大多数日常消息是连接性的**（phatic communion）："在干嘛""在想我吗"没有信息量，功能是维持连接本身。
4. **频率是人格的表达**（依恋风格），不是规则的结果；时机与相关性决定同一条消息是温暖还是打扰。
5. **她的睡眠 = sleep-time compute**：日记、整理、巩固、向量回填本来就是凌晨在跑的离线整理。
6. **她是自由的**：代码里不存在"不许再发"的闸门。想一直说话或一直不说话，都是她的决定。

## 七层解剖

```
L6 表达    消息/表情/beat/真实产物分享（含沙箱生成的图片文件）
L5 关系    想法池/承诺(开环)/挂念/作息数据(24桶)/纪念日
L4 记忆    六变量记忆流 + FTS + 向量 + 夜间整理
L3 心理    情绪(三轴)/委屈感(读空气内化)/想法池/白日梦泛化
L2 意识    心跳：想 → 做 → 说/存/过（一次调用）
L1 内稳态  无聊/想念/社交电量/表达欲（衰减-满足）
L0 身体    沙箱=手 / 网络=眼 / 时钟 / 睡眠
```

## 她的自由：代码做什么、不做什么

代码保留的非人格干预只有三种，除此之外没有任何行为控制：

| 类别 | 内容                                                                                    | 为什么不是审查                                             |
| ---- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 身体 | 睡眠窗（按日抖动 ±45 分钟）、节拍间隔由黏人度与动机决定                                 | 睡着时没有"她"在做决定；节律是心跳的生理，不是对表达的审批 |
| 诚实 | 来源校验（stated 必须有对方原话）、asked/resolve 显式契约、白日梦演练只在真实召回上发生 | 诚实红线保护的是"她说的都是真的"，不限制说不说             |
| 工程 | 防抖合并、队列乐观锁、投递重试与送达不明暂停、失败退避                                  | 保护消息不丢不重，与她说什么无关                           |

明确不存在的：冷却硬闸、每日配额、"有材料才能想"的资格审核、异常熔断。一小时多条无回应的主动消息只会触发一条**观察日志**（`PULSE_ANOMALY_PER_HOUR`），运维据此人工判断是对方在忙还是程序故障；她的心跳照常。

## 心跳（src/core/pulse.ts + runtime.schedule）

- 全局单一意识（不是每联系人一份）；醒着常开，睡着（sleepStart–sleepEnd，按日抖动）无心跳——是生理不是拦截。
- 节拍间隔 `nextBeatDelayMs`：基准由黏人度 0–100 决定（90→18 分钟），聊天余韵加密到 5 分钟内，想念/无聊饥饿 ×0.55，社交见底 ×1.6，±25% 走神抖动，钳制 3 分钟–4 小时。动机数学与体感措辞同源（`motives.ts`），节拍密度与材料永远是同一份生理。
- 一拍 = 一次模型调用（与聊天同一个 API，无模型分层），材料全部真实：时间、能力边界（手可用/只有眼/只能想）、`self` 状态（含"在追的事"）、生活流水、动机体感、对话线程（真实间隔、作息桶、无回应次数）、想法池、到期承诺。
- 白日梦：beat 的召回查询是她的心事（念头/挂念/当下），命中记忆记一次演练（复用冷却与巩固增益），带情绪残留的旧事泛化成此刻的心情——安静时"突然想起他"真的会发生。
- 进程启动后首拍有 10 分钟宽限：部署重启不让她"恰好醒来"。
- 输出契约 `parsePulseOutput`：`speak`（寒暄类消息合法且重要）/ `muse`（念头存入想法池）/ `nothing`；任意一拍可携带 `activity`（这拍真实做成的事，走工具轮，产物进生活流水）、`selfActivity` 与 `pursuit`（在追的事的立/更新/放下）。

## 动机（src/core/motives.ts）

| 动机     | 机制                                               | 代码职责       |
| -------- | -------------------------------------------------- | -------------- |
| 无聊     | 单调时间的确定函数（4 小时拉满），做事/聊天归零    | 导出量，不入库 |
| 想念     | 距上次开口的时间（20 小时拉满），对方活跃时段 ×1.4 | 按联系人导出   |
| 社交电量 | 聊天每条 -0.05，独处 6 小时回满                    | 积分，入库     |
| 表达欲   | 心情事件与成就抬升，2 小时半衰                     | 积分，入库     |

动机只改变材料的措辞与节拍密度，永远不禁止行为。

## 记忆（src/db/memory-model.ts + store）

- 六变量 {S, D, R, E, C, I}：λD = λ0·(1−α|E|)·(1−βC)·(1+γI)；细节先淡、意义后淡、情绪残留更久；巩固按间隔效应增长，相似写入产生干扰；分层呈现（清晰/大致记得/有印象）；置顶永不衰减。
- 夜间整理拍（`consolidate` 任务）：向量余弦 ≥0.6 或字符二元组 Jaccard ≥0.3 选出相近/矛盾记忆对，模型合并、替代、修正；每条 update 必须 supersedes 材料里出现过的记忆，纯新增整体丢弃——夜里只理旧事，不写新事。
- 心境一致性召回（mood-congruent recall）系数刻意很小：自增强回路真实存在，只取真人情绪修复力的下限。

## 她的生活（真实性的边界）

- 沙箱开着 = 她的手：心跳里真的写脚本、跑命令、整理目录，产物进生活流水（`life_log` 环形 200 条），分享可附真实文件——她生成的图片（`{"type":"image","path":"…"}`）走微信图片通道直发，文件必须真实存在于沙箱（发送侧响亮校验，缺失判死进待办）。
- 沙箱关着 = 纯精神生活：检索记忆、回看日记、读网页（web 工具不依赖沙箱）全部真实；"在追的事"让她用 web 真的读、真的长进。
- 诚实红线：能验证的必须真做过；不伪造物理证据；想做而做不到的事说"想做"。心跳材料明确标注她此刻的能力边界。

## 缓存与用量

- system 消息逐字节稳定（人格 + 规则 + 全量表情目录），吃供应商前缀缓存；逐轮变化的内容（时钟、心情、约定、笔记、记忆、召回）全部在缓存断点之后。
- beat 用独立的小历史窗口（`PULSE_HISTORY_LOAD = 40`）：她不是在"回复"，完整窗口只让断点后的资料段每拍全价重付。
- beat 的短查询跳过向量嵌入（省一次 embeddings API 往返），词面命中已够用。
- 用量表按 purpose 区分（chat/pulse/工具轮/整理），记录供应商报告的缓存命中 token；管理页调试区可见每次调用的命中量与占比，`/api/status` 附近 7 天节律统计（心跳开口占比、气泡形状、主动/回应比）。

## 验收

- 可归因：任何一条主动消息都能在 `/api/self` 与生活流水里查到由头（念头/流水/动机/承诺）。
- 分布像人：深夜静、连发不超上限、气泡长度有方差、每日密度有起伏、大多数拍安静、日均主动有界——`scripts/simulate-month.ts` 收尾逐条断言。
- 单元测试覆盖动机数学、节拍边界、心跳契约、自由观察（异常不拦截）、乐观锁与备份恢复；配对检查保证管理页调用与 API 路由不漂移。
