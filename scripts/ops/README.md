# scripts/ops — 一次性运维脚本

这些脚本**不参与构建、测试或运行**，是开发过程中用来操作远程主机的临时工具。
保留它们是为了留下操作记录，需要时可以直接复用。

| 脚本               | 用途                                                                    | 敏感信息                   |
| ------------------ | ----------------------------------------------------------------------- | -------------------------- |
| `ssh-run.mjs`      | 通过 SSH 在目标主机执行单条命令，密码经临时 askpass 文件传递            | 密码从 argv 传入           |
| `ssh-script.mjs`   | 把本地 shell 脚本以 base64 传到目标主机执行，避免多层引号问题           | 同上                       |
| `scp-get.mjs`      | 通过 SCP 从目标主机拉取备份目录                                         | 同上                       |
| `container-sh.mjs` | 在 ATRI 容器内执行 shell 片段（经 stdin 传入，避免本地 shell 二次解释） | 同上                       |
| `host-sh.mjs`      | 在 ATRI 宿主机执行 shell 片段                                           | 同上                       |
| `sandbox-debug.sh` | 在服务器上排查沙箱挂载、开关状态和文件时间线的一次性脚本                | 从服务器 .env 读取管理密码 |

**为什么放在子目录里**：`scripts/` 根目录只保留 `package.json` 真正调用的入口
（`build.mjs`、`test.mjs`、`backup.ts`、`restore.ts`）。API 配对检查和烟雾测试已经合并进
`test.mjs`（`--smoke`），根目录不再单独留脚本。这里的脚本没有任何引用，混在一起会让
"这个文件还要不要"变成每次都要重新判断的问题。

`ssh-run.mjs`、`ssh-script.mjs` 和 `scp-get.mjs` 会接触主机登录，因此不要在不受控的环境里运行。
